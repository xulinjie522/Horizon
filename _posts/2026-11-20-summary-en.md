### [PostgreSQL 19.0 Release Notes Published](https://www.postgresql.org/docs/release/19.0/) ⭐️ 9.0/10

The PostgreSQL project has published the official release notes for PostgreSQL 19.0, a new major version of the open-source relational database. The release notes page is the primary documentation of what changed in this version. The material supplied here contains no feature-level detail, so specific additions, deprecations, performance changes, and upgrade requirements are not summarized; readers evaluating an upgrade should consult the notes directly.

hackernews · linzhangrun · Nov 20, 03:45 · [Discussion](https://news.ycombinator.com/item?id=50569890)

**「Background」** PostgreSQL major releases are followed by point releases, which is why the discussion asks whether to wait for 19.1 or 19.2 before upgrading. The official release notes date PostgreSQL 19.0 to 2026-11-19 and list a new REPACK command for reclaiming disk space and reorganizing table contents.

**「Community Discussion」** Commenter murkt argued this is &quot;the most bug-free .0 release of Postgres,&quot; while noting a personal practice of waiting for at least a .1 or .2 point release before upgrading, and asked whether that habit should be abandoned this time. A second comment only points to an earlier Hacker News thread on the release.
